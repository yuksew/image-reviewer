## 3. 自分で決めた点（1 行ずつ理由）

1. **口を 1 つだけ足した**（`GET /api/scan`）。§3.4 は「`scan_running` は作らない」と決めているが、
   それは**409 を返さない**ことの話で、**画面に「走査中です」を出す材料**が要る（E-6）。
   **読むだけ**の口 1 つに絞った（`POST` は今までどおり `scan_guard` が待たせるだけ）。
2. **`scan_state()` は `self._lock` を取らない。** 取ると「走査中にだけ答えない口」になる（試験 90 で固定）。
   印は `scan_guard()` が立てて `finally` で消す（**走査は 1 本**なので入れ替わりの競合は考えない）。
3. **設定の画面は「要る物だけ」**（バックアップと段 3 の印）。接続・閾値・タガー・テーマは置いていない
   （P7 の教訓「要らない物を作らない」）。**復元は CLI の 1 行**（危険な操作を画面の口に置かない。§3.3）。
4. **「最後に取った時刻」は `daily` / `manual` だけ**から組む（再確認 D-5。`pre-topup` は一覧に出すが数えない）。
5. **段 3 の出し分けは「選んだ枚のパス」から**（`GET /api/assets` を 1 回だけ引く。枚ごとに `GET` を並べない）。
   **どの置き場にも入っていない枚・確かめられないときは出さない**（`_stage3_ok` と同じ「安全側」）。
   文は「印がありません」と「確かめられません」を**分ける**（家風「数を黙って捨てない」）。
6. **走査中の 1 行は 5 秒ごとに見直す**（毎秒の残り時間の書き換えには触らない。`GET` は書かない）。
7. **`target_exists` の文**は「元の場所に既にファイルがあります。**「別名で戻す」で戻せます。**」とし、
   「いま消す」は**ボタンだけ**にした（再確認 D-1・G-1 の推奨）。
8. **`--screen settings` を足した**（画面を 1 つ作ったので `gui_layout` の単位も 1 つ増やす。P6-2 の `asset` と同じ）。
9. **複製の走査中の表示は「応答を差し替えて」見る**。本物の走査は複製では一瞬で終わる。
   代わりに**本物の `POST /api/scan` 中の `GET /api/scan`** を別に測った（`本物の走査=true`）。
10. **`gui_layout` の期待値は毎回 API から引く**（`last_error` の有無・印の数・群の数）。
    前提が無いときは **NG にせず「注意」**（監査 D-6 の流儀。複製を作り直すたびに落ちない）。

## 6. 設計の穴（気づいた点）

1. **自分の新しい試験が 6 回に 1 回落ちた**（`test_the_scan_state_is_read_only`）。
   原因は**アプリの背景のタイマー**（日次は**起動した直後に 1 回**動く。設計 §0.12-1）で、
   `settings` と WAL が動く分を「`GET` が書いた分」と見分けられなかった。
   **試験の側でタイマーを止めてから測る**形に直した（10 回連続で緑）。**実装は正しい**。
   ——「`GET` が書かない」を**ファイルの署名**で見る試験は、**背景の仕事を止めてから**測るのが要る
   （P8-4 の再確認が使った「全表の中身の sha256」でも同じ罠がある）。
2. **`/api/scan` の POST と GET が同じ道**なので、`GET` を足すときに**認可の非対称**が生まれやすい
   （`POST` は書き込み、`GET` は読むだけ）。`actor` の語彙は `GET` でも検査する形にした（試験 89）。
3. **`#/settings` は `frontend-design.md` §3 の画面一覧に元からあった**が、
   **P8-5 まで実体が無かった**（`frontend-design.md` §10 のファイル一覧の `settings.ts` も空欄だった）。
   「一覧にあるのに無い画面」は P6 のまとまりレビュー（点検 A2）と同じ形の穴である。
   この段では**バックアップと段 3 の印だけ**を作った（他の項目は利用者から要望が出た段で）。
4. **段 3 の出し分けは「画面の判断」**であって**サーバの規則ではない**（サーバは 409 で断る）。
   食い違っても**危険側には倒れない**（印が無ければ 409 で 1 枚も消えない）が、
   **同じ規則が 2 か所にある**（`deletions.py` の `_stage3_ok` と `pending.js` の `stage3Allowed`）。
   片方を直したらもう片方も直す（`gui_layout` が API と突き合わせて見ている）。
