## 7. 質問（G。判断が要る物に推奨つき）

- **G-1 中黒の規則をどう決めるか。** 正 §6 の「使わない語」と §6 の各行が食い違っている（§5-1）。**推奨**: (a) 名詞の対（写真・その他、段 1・2、人数・人物）だけ中黒、(b) メタ情報は括弧か読点（「最近の削除 193（あと 3:12）」「候補 20 群、55 枚」）、(c) 文は「。」で切り、中黒で文を繋がない。この 3 行を §6 の「使わない語」の段に書き、§6 の各行と `gui_smoke` / `gui_layout` の検査を合わせて直す。
- **G-2 「枚」「物」の扱い。** 推奨: 「枚」は助数詞だけに使い、名詞には「画像」（§17 の「実体（asset）」ではなく、画面では「画像」で通す）。「物」は仮名の「もの」に。§6 の冒頭「名詞は利用者の言葉で」の下に 1 行足す。
- **G-3 英語の内部値を画面に出さない規則。** 推奨: `kind` / `source` / `wants` / ジョブの `kind` / `state` は**全部ラベルの地図を通す**（`jobs.js:18` の `STATE_LABEL` と同じ形）。地図に無い値は「その他（値）」の形で出す。バッククォートは HTML に書かない。
- **G-4 「バックアップ」の 1 回分を何と呼ぶか。** 候補: バックアップ / 控え / スナップショット / 写し / 世代。**推奨**: 画面と README は「バックアップ」、数えるときは「世代」（「7 世代」は README に既にある）。`backup.py` の中の「写し」は内部の語として残してよい。§17 に行を足す。
- **G-5 「実体」の意味。** §17 は asset（内容で同定される画像）、画面はファイルそのもの。**推奨**: 画面の「実体」を「ファイル」に（「実体 1.7 MB」→「ファイル 1.7 MB」、「実体を消す」→「ファイルを消す」、「実体が見つかりません」→「ファイルが見つかりません」）。§17 はそのまま。
- **G-6 「捕獲」を残すか。** 「訳を捕獲」「捕獲中…」「訳が未捕獲」は設計の語で一貫しているが、漢語としては強い。**推奨**: ボタンは「訳を捕獲」のまま（§17 の「監視」の説明と合う）、文の中の「未捕獲」だけ「捕獲していない」にほどく（W-22）。
