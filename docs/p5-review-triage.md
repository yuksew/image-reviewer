## 3. 実装の最初に確かめること（未確認のまま進めない）

1. **F1**: Python 同梱の SQLite で `CREATE UNIQUE INDEX ... WHERE ... IS NOT NULL`（部分索引）が効くか。1 行のテスト。
2. **F3**: B1 を採るので mtime には依存しない。`os.replace` の mtime の挙動は確かめなくてよい。
3. **F5**: pHash の実費用を**復号込み**で測る（1,000 枚）。純 Python の DCT が支配的か復号かで、pHash を背景ジョブにするかが決まる。
4. **F2**: Pillow の `F` モード画像に `GaussianBlur` が効くか。効かなければ SSIM は numpy で書く（**numpy は入れるので、最初から numpy で書いてよい**）。
5. **F6**: JSON ストアの競合は P5-0 で消える。P5-0 のテストで「`scan` が判断を消さない」を示す。
6. **F7**: `path_map` か `locations[]` か。**`locations[]` に一本化**して契約を直す（1 回目の C17 をここで閉じる）。
