## 1. 総合判定

**「一部に不揃い」**。

根拠を 1 行で: 文そのものは日本語として読めるが、**(a) 同じ種類の物に複数の書き方**（日付と時刻が 5 形式、「無い」の表し方が 5 通り、通知の文末の「。」が有ったり無かったり、ボタンが終止形と名詞で揺れる）、**(b) 独自の語が主画面に素で出る**（入れ物・控え・語釈・捕獲・実体・置き場）、**(c) 空の状態と確認の文に「次の一手」が無い**（走査する画面が無いのに「フォルダを追加すると」、無いボタン「いま取る」への案内、「消す用意をする」）が、初見の利用者を止める。**中国語っぽさは前の監査でほぼ直っている**（§6）。

## 4. 最も直すべき 20 件（初見の利用者が困る順）

1. **C-1** 空のライブラリに「走査するフォルダを追加すると、ここに並びます。」— 追加する画面が無い。初見の利用者は最初の画面で止まる。
2. **C-2** 「設定の「いま取る」で今すぐ取れます。」— そのボタンは無い（「取り直す」）。今回の修正で入った文。
3. **C-3** 「193 件（取り消せるのは 0 件）」の下に「取り消せる削除」の見出しと 193 行の「戻す」— 見出しと中身が矛盾。
4. **C-4** 「2 枚を消す用意をする」— 削除の主ボタンで何が起きるか分からない。確認に「戻せるか」が無い。
5. **C-5** 「選んだ N 枚を削除へ回す」— 「回す」が通じない。削除されると読める。
6. **C-6** 「最後の 1 つが 2 枚あります。ほかに実体がありません。 これも消す」— いちばん危ない選択の前の文が内部の語。
7. **D-1 / D-2 / D-3 / D-4 / D-5** 「入れ物」「語釈」「控え」「捕獲」「実体」— 主画面に初見で通じない語が 5 つ。
8. **C-7 / C-8** 「消せません（409）」「比較できません: Failed to fetch」— 番号と英語だけで、次の一手が無い。
9. **A-1** 日付と時刻が 5 形式（画面は現地、CLI は UTC の ISO）。
10. **C-9 / B-5** 進行と完了と状態の語の揺れ（「読み込んでいます。」「終わりました」「完了」「待っています」）。
11. **C-12 / C-13** 「テーマ: 暗幕 / 表」「密度: 普」— 1 字と題材の語で、初見で意味が取れない。
12. **E-1** 上部の注意書きが 91 字の 1 文＋工程番号「P7」＋開発者向けの文。全画面に常に出る。
13. **A-6 / F-2** 「戻せます （エージェント…」— HTML の改行が空白になり、括弧の前に隙間。写し 7 か所。
14. **A-4** 通知の文末の「。」の有無が画面ごとに違う（注記は無し、削除と設定は有り）。
15. **C-15 / C-16** ボタンの形の揺れ（「保存」と「保存する」、「解除」「中断」「再読込」の名詞形）。
16. **B-1 / B-2 / A-9** 「…しきい値 6 より大きい（画素はほぼ別物です）」「画像がある（3 枚は分かりません）」「弱い＝別の絵」— 常体と敬体の混在と「＝」。
17. **C-18 / A-14** CLI の「走査: 見た 299 / 画像 0 / 新規 0 / 既知 299」— 「画像 0」が読めない。
18. **A-2** CLI の「DB 3428.0 KB」「作った時刻 2026-10-18T18:19:21Z」— 画面の形と違う。
19. **C-19** 日本語の help に英語の骨組み（usage / positional arguments / show this help message and exit）。
20. **A-12** 「無い」の表し方が 5 通り（— / （なし） / （メモなし） / 理由なし / タグなし）。

## 7. 質問（G。規則の選択に関わる物。推奨つき）

- **G-1 ボタンの形をどちらに揃えるか。** いま終止形が 30 余り、名詞形が 9（解除・中断・再読込・再走査・等倍・別物として確定・全部ボツ・座標 JSON・切り出し）。**推奨**: 終止形に揃える（「解除する」「中断する」「再読込する」「別物として確定する」）。「等倍」「全部ボツ」のように名詞が自然な物だけ例外として §6 に列挙する。
