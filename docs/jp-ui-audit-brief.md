## 1. 見る観点（**この 6 つを全部**）

### A. 表記の規約（**日本語のソフトとしての作法**）
1. **数字と英字**: **全角と半角の混在**がないか（**半角数字が原則**か）。**桁区切り**（3,120 / 3120）。**単位との間の空白**（「3 件」「3.2 MB」「1024 × 1024」「0.5 秒/枚」）。
2. **句読点**: **「、」「。」の使い方**（**文末の「。」の有無が揺れていないか**。**ボタンや見出しには付けない**のが普通）。**読点の位置**（「〜は、〜」）。**三点リーダ**（… か ... か）。
3. **括弧**: **全角（）と半角()** の混在。**「」と（）の入れ子**（「…（…）」）。**括弧の前に空白**が入っていないか。
4. **中黒「・」**: **名詞の対だけ**に使われているか（前の監査の規則 1 と一致するか）。
5. **日付と時刻**: **`2026-10-18` / `2026/10/18` / `10 月 18 日` / `20261018`（フォルダ名）の混在**。**時刻**（`20:01` / `20 時 1 分` / 「あと 4:59」）。**JST と UTC の表示**。
6. **記号**: **「〜」と「～」**・**ハイフンとダッシュ**・**`/` と「または」**・**`:` と「：」**。

### B. 文体（レジスタ）
7. **です・ます と だ・である の混在**（**画面ごと・同じ画面の中で**）。
8. **「〜します」と「〜しました」の使い分け**（**これから**と**済んだ**）。
9. **体言止め**（見出しで使うのは自然か）。
10. **丁寧さの段階**: **エラーで急に丁寧／乱暴になっていないか**。**同じ種類の文が同じ調子か**。
11. **主語の省略**: **誰の視点か分からない文**がないか。
12. **受動態の多用**（「〜されます」の連続）。

### C. 画面の作法（**日本語のソフトの慣習**）
13. **ボタンの語**: **動詞か名詞か**が揃っているか（「削除」と「削除する」の混在）。**破壊的操作**の語（「削除」「取り消す」「元に戻す」「戻す」）。
14. **確認の文**: **何が起きるか**が書いてあるか（「本当に削除しますか」だけで終わっていないか）。
15. **空の状態**: **次に何をすればよいか**が書いてあるか。
16. **エラーの文**: **「何が起きたか」＋「どうすればよいか」**の 2 つがあるか。**技術用語の生の露出**。
17. **進行と完了**: **「〜中です」「〜しました」**の使い方。**パーセントの見せ方**。
18. **数値の見せ方**: **件数と単位**（「3 件」）。**0 件のとき**の文。

### D. 用語（**初見で通じるか**）
19. **このアプリ独自の語**が**初見で通じるか**: 「控え」「入れ物」「下ごしらえ」「さばく」「まとまり」「要求」「来歴」「語釈」「注記」「印」「保留」「ゴミ箱」。
   **一般的な語との対応**（控え＝バックアップ、入れ物＝フォルダ）を**表**にして、**「初見で通じる／文脈があれば通じる／通じない」**を 3 段階で判定。
20. **`docs/design.md` §17（用語集）との整合**（**用語集に無い語**・**用語集と違う使い方**）。
21. **同じ物に複数の語**（前の監査の §4 の表を**再確認**し、**直ったか**を見る）。

### E. 読みやすさ
22. **1 文の長さ**（**40 字を超える文**を数える）。**1 行の長さ**（**画面で折り返す行**）。
23. **漢語と和語のバランス**（**漢語が続いて硬い**箇所）。
24. **同じ語の繰り返し**（1 画面で同じ語が何度も出る）。
25. **コピーして使えるか**（エラーの文をそのまま検索できるか）。**記号が読み上げで邪魔にならないか**。

### F. 画面の実物（**必ず見る**）
26. **本物の Chrome で**（複製にサーバを立てて）、**指示書の入口 11 個＋操作後の状態**を開き、**見えている文字を全部書き写す**（`tools/gui_shot.mjs --base <複製> --hash "#/..."` と自分の Chrome 検査）。
   **写真は `.tmp-audit-redo/jp-ui/` に**。**`grep` で文字列リテラルを全部出す**のも**併用**（**片方だけだと漏れる**）。
27. **折り返しと禁則**: **句読点が行頭に来ていないか**・**括弧が行頭/行末で変になっていないか**・**数字と単位が行をまたいでいないか**（`gui_layout` の 3 窓で見える）。
